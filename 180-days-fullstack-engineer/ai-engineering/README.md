# AI Engineering Roadmap

This folder maps AI Engineer, ML Engineer, MLOps Engineer, LLM Engineer, Applied AI Engineer, and AI Product Engineer skills onto the existing 180-day full-stack roadmap.

The rule is simple: no passive learning. Every AI, ML, MLOps, or product topic must produce code, tests, evals, deployment notes, architecture docs, runbooks, incident reports, product docs, or interview explanations.

## Execution Rule

Use the resource only long enough to ship the artifact for the current week. If a course section does not improve the current artifact, skip it.
