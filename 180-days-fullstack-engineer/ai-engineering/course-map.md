## Resource Roles

| Resource | Use it for | Do not use it for |
|----------|------------|-------------------|
| [CS50x](https://cs50.harvard.edu/x/) | computational thinking, algorithms, C/Python/SQL mental model | completing every problem set before building |
| [CS50 Python](https://cs50.harvard.edu/python/) | Python CLI, tests, file I/O, OOP basics | delaying backend work |
| [CS50 Web](https://cs50.harvard.edu/web/) | Django/REST/testing/scalability comparisons | replacing the existing Node/Next roadmap |
| [CS50 AI](https://cs50.harvard.edu/ai/) | search, ML, and AI foundations when concepts are weak | becoming an ML researcher |
| [Kaggle Learn](https://www.kaggle.com/learn) | Python, Pandas, SQL, intro ML vocabulary | competitions or notebook-only work |
| [MIT 6.006](https://ocw.mit.edu/courses/6-006-introduction-to-algorithms-spring-2020/) | algorithmic explanation and complexity thinking | proof-heavy detours not tied to DSA logs |
| [freeCodeCamp Back End APIs](https://www.freecodecamp.org/learn/back-end-development-and-apis) | Node/Express/API reinforcement | duplicate backend projects |
| [DDIA](https://www.oreilly.com/library/view/designing-data-intensive-applications/9781491903063/) | reliability, scalability, data systems tradeoffs | reading cover to cover before writing designs |
| [AWS Skill Builder](https://aws.amazon.com/training/digital/) | IAM, S3, RDS, Lambda, cost, and deployment basics | certification grinding |
| [IBM DevOps and Software Engineering](https://www.coursera.org/professional-certificates/devops-and-software-engineering) | Docker, CI/CD, cloud-native, serverless vocabulary | replacing the existing deployment weeks |
| [Hugging Face LLM Course](https://huggingface.co/learn/llm-course/chapter1/1) | transformers, tokens, embeddings, open-source LLM workflows | fine-tuning before RAG/evals work |
| [Hugging Face Agents Course](https://huggingface.co/learn/agents-course) | tools, actions, observations, agent workflows | autonomous agents without guardrails |
| [Hugging Face MCP Course](https://huggingface.co/learn/mcp-course/unit0/introduction) | MCP concepts and tool servers | replacing normal API/service design |
| [DeepLearning.AI ML Specialization](https://www.deeplearning.ai/specializations/machine-learning) | baseline ML vocabulary and error analysis | all assignments if they block capstone progress |
| [DeepLearning.AI Machine Learning in Production](https://www.deeplearning.ai/courses/machine-learning-in-production) | ML lifecycle, drift, monitoring, production constraints | generic ML modeling without production controls |
| [IBM Generative AI Engineering](https://www.coursera.org/professional-certificates/ibm-generative-ai-engineering) | genAI, RAG, evaluation vocabulary | duplicating the Hugging Face/OpenAI implementation path |
| [W&B Models](https://docs.wandb.ai/models) | experiment tracking, model registry, eval logging | dashboards without decisions |
| [OWASP LLM Top 10](https://owasp.org/www-project-top-10-for-large-language-model-applications/) | AI security and prompt injection risks | scare lists without mitigations |
| [Google Cybersecurity Certificate](https://grow.google/certificates/cybersecurity/) | IAM, privacy, threat thinking | replacing OWASP or capstone security evidence |
| [Google Project Management Certificate](https://www.coursera.org/professional-certificates/google-project-management) | stakeholder communication and project artifacts | nontechnical busywork |
| [YC Startup School](https://www.startupschool.org/) | MVP validation, customer discovery, startup thinking | pitch theater without user evidence |
| [Google Technical Writing](https://developers.google.com/tech-writing) | clear docs, memos, architecture reviews | polishing instead of proving |
