# Full-Stack AI Engineering Skill Stack

This stack preserves the original full-stack roadmap and layers AI/ML/MLOps skills at the point where the engineering foundation can support them.

| Stage | Weeks | Role signal | Skills | Proof |
|-------|-------|-------------|--------|-------|
| Foundations | 01-03 | junior software + data-capable engineer | CS50-style algorithmic thinking, Python, Pandas, NumPy, SQL basics, DSA habit | Python CLI, data cleaning script, tests, DSA logs |
| Backend architecture | 04-06 | backend engineer | REST, OpenAPI, auth, schema design, indexing, load tests, DDIA basics | URL shortener/module, API design doc, deployed endpoint, load notes |
| Cloud and data systems | 07-09 | production backend/cloud engineer | AWS basics, IAM, S3/RDS, serverless fit, data pipelines, clean architecture boundaries | cloud ADR, IAM notes, rollback checklist, data pipeline notes |
| LLM builder | 10-12 | LLM application engineer | tokens, context, structured outputs, RAG, embeddings, agents, tool calling, MCP basics | model gateway, RAG module, eval seed set, agent CI gate |
| MLOps and LLMOps | 13-15 | MLOps/AI reliability engineer | experiment tracking, model/data versions, evals, drift, monitoring, rollback, incident response | MLOps design, eval report, dashboard notes, AI postmortem |
| Product and leadership | 16-18 | senior full-stack AI engineer | AI security, PRDs, user interviews, MVP validation, stakeholder memos, final architecture review | risk register, PRD, case study, readiness scorecard, interview pack |

## Quality Bar

By Day 180 you should be able to explain:

- How ML differs from traditional software.
- How LLM apps fail in production.
- How to evaluate a RAG system.
- How to design an AI feature safely.
- How to deploy and monitor an AI service.
- How to reduce LLM latency and cost.
- How to handle hallucinations.
- How to build feedback loops.
- How to compare OpenAI, Anthropic, and local models.
- How to design AI product metrics.
- How to communicate technical tradeoffs to non-technical stakeholders.
