# AI Engineering Artifact Index

Use this folder for the weekly applied AI proof artifacts referenced by the roadmap, weekly READMEs, and progress tracker.

Each artifact should answer:

- What user problem does this solve?
- What non-AI baseline exists?
- How is success measured?
- How is quality evaluated?
- How is cost controlled?
- How is reliability monitored?
- What can fail in production?
- What evidence proves the claim?
