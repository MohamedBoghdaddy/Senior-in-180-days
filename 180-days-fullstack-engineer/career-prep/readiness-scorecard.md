# Unified Readiness Scorecard

Score each area from 0 to 4.

| Area | 0 | 2 | 4 |
|------|---|---|---|
| Full-stack delivery | no working app | app works locally | deployed, tested, documented, reliable |
| Backend architecture | ad hoc endpoints | documented API and schema | scalable design with tradeoffs and incidents |
| DSA/interviews | inconsistent practice | patterns logged | 500 solves with redos and mocks |
| CS fundamentals | scattered notes | weekly notes | interview-ready OS/network/DB explanations |
| Python/data | scripts only | tested CLI and data pipeline | repeatable data workflow with docs and tests |
| Cloud/DevOps | local only | Docker/CI notes | runbook, rollback, IAM/secrets, deployment evidence |
| LLM/RAG/agents | demo prompt | RAG/agent prototype | evaluated, cited, monitored, safe workflow |
| MLOps/evals | no evals | golden dataset | CI evals, drift notes, model/version comparison |
| AI security | vague concerns | threat model | prompt-injection tests, privacy checks, risk register |
| Product/leadership | feature list | PRD/MVP note | user evidence, stakeholder memo, case study |

Graduation requires no area below 2 and at least six areas at 4.
