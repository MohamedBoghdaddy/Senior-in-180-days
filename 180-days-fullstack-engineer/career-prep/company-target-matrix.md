# Company Target Matrix

Use this to map portfolio evidence to target roles. Do not chase company trivia; build proof that generalizes.

| Company type | What to emphasize | Portfolio evidence |
|--------------|-------------------|--------------------|
| Google / Meta | algorithms, systems, scale, clean design | 500 DSA track, system design docs, performance notes |
| Amazon / Microsoft | ownership, backend systems, reliability, product delivery | runbooks, postmortems, deployment pipeline, capstone |
| OpenAI / Anthropic | applied AI, evals, safety, product quality, tools | RAG, agents, eval reports, AI safety hardening |
| Nvidia | systems performance, inference infrastructure, observability | model gateway, latency/cost tracking, runtime notes |
| Tesla / SpaceX | reliability, debugging, constraints, operational intensity | incident drills, rollback plans, root-cause analysis |
| Stripe | API quality, correctness, reliability, security | OpenAPI, auth/RBAC, idempotency, audit logs |
| Databricks | data systems, pipelines, ML/AI product integration | DB design, RAG ingestion, eval datasets, query plans |
| Modern AI startups | full-stack speed plus production judgment | AI product PRD, working demo, evals, cost controls |

## Rule

Every company target must map to at least three artifacts, not aspirations.
