# Target Roles

Use this file to map artifacts to roles. A role is ready only when you can show proof, explain tradeoffs, and describe failures.

| Role | Must prove | Core artifacts |
|------|------------|----------------|
| Full-Stack AI Engineer | frontend/backend product, AI workflow, deployment, evals | capstone, RAG module, eval report, production checklist |
| Applied AI Engineer | user problem, model integration, quality and safety | PRD, model gateway, RAG/agent demo, eval dataset |
| AI Product Engineer | user workflow, metrics, UX tradeoffs, cost/reliability | user interviews, PRD, MVP spec, cost/latency report |
| ML Engineer | data pipeline, baseline model/eval thinking, model lifecycle | data cleaning pipeline, model/version notes, eval report |
| MLOps Engineer | deploy/monitor/rollback AI systems | CI eval gate, drift notes, dashboard, incident postmortem |
| LLM Engineer | LLM app architecture, RAG, agents, provider tradeoffs | LLM service interface, RAG design, agent workflow, safety tests |
| Backend Engineer | APIs, databases, reliability, security | OpenAPI, schema/index notes, runbooks, incident reports |

## Rule

Every resume bullet should point to a repository artifact, not a claim.
