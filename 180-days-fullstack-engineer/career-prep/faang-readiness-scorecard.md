# FAANG Readiness Scorecard

Score each category from 1 to 5. A 4 means interview-ready with minor polish. A 5 means strong signal.

| Category | Evidence | Score |
|----------|----------|------:|
| DSA pattern recognition | 500-problem log, redo history, weak-pattern list | 0 |
| DSA communication | mock rubric scores and explanations | 0 |
| CS fundamentals | OS/network/DB artifacts | 0 |
| System design | architecture docs and design drills | 0 |
| Backend depth | API, auth, RBAC, database, tests | 0 |
| Reliability | runbooks, observability, postmortems | 0 |
| Security | threat models and hardening notes | 0 |
| Behavioral stories | story bank linked to artifacts | 0 |

## Ready Threshold

- No category below 3.
- DSA, system design, backend, and communication at 4 or higher.
- At least five mock interviews scored with the rubric.
