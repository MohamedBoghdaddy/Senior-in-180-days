# Weekly Interview Checkpoints

Use this file at the end of every 10-day sprint. The checkpoint is not extra work; it packages the DSA and CS fundamentals evidence that already happened during the sprint.

## Required Checkpoint Evidence

- Total DSA count for the sprint and running total toward 500.
- Easy, Medium, Hard, and redo counts.
- Three strongest patterns and three weakest patterns.
- One written CS fundamentals artifact.
- One short answer bank with at least three interview questions.
- Mock interview score when the sprint includes a mock task.

## End-of-Sprint Questions

- Which pattern became easier this sprint?
- Which mistake repeated more than once?
- Which problem must be redone within 7 days?
- Which CS fundamentals answer can I explain without notes?
- Which capstone artifact proves this learning is connected to production engineering?
