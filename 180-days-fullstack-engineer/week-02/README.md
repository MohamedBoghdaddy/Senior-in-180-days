- Product/communication topic: Describe how cleaned data would improve a user-facing dashboard or task workflow.
- Resource mapping: primary: [Kaggle Pandas](https://www.kaggle.com/learn/pandas), [Kaggle SQL](https://www.kaggle.com/learn/sql), [CS50 Python](https://cs50.harvard.edu/python/) unit tests and file I/O. Optional: [Kaggle Intro ML](https://www.kaggle.com/learn/intro-to-machine-learning) first lesson only for vocabulary.
- Required artifact: Data cleaning script or notebook exported to a repeatable Python command, transformation examples, and tests.
- Interview explanation: Explain the difference between raw data, cleaned data, features, labels, and application data.
- What not to study this week: Model training, Kaggle competitions, heavy statistics, and replacing the existing JS/browser tasks.
