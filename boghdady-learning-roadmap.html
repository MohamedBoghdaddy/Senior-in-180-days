6-Month Learning Roadmap

Built for ~15–20h/week of focused learning. Adjust if you're working full-time: cut to 10h/week and extend each month by 2–3 weeks.

Month 01 · Foundation
Close the Gaps
  • CS50x — Weeks 1–6 (C, Python, SQL, algorithms)
  • NeetCode: Arrays, Hashing, Two Pointers (daily 45min)
  • Google Technical Writing One & Two (free badge)
  • Google Cloud Skills Boost Gen AI path (8–10 badges)
  • Start OSTEP OS book — read Chapters 1–15 (processes, memory)
CLI task manager in C with file I/O persistence
~18h/week · ~72h total
Month 02 · Full-Stack Depth
Formalize the Stack
  • CS50x — Weeks 7–11 + Final Project
  • Full Stack Open — Parts 0–5 (React, Node, MongoDB)
  • NeetCode: Stacks, Queues, Binary Search patterns
  • Docker fundamentals — Maximilian's Udemy course (buy at sale)
  • AWS Cloud Practitioner prep (Skill Builder free content)
Full-stack notes app: React + Node + MongoDB + Docker + Railway deploy
~20h/week · ~80h total
Month 03 · AI Engineering
Build AI Systems
  • Hugging Face AI Agents Course (free cert)
  • LLM Engineering: Master AI & LLMs (Udemy, buy at sale)
  • DeepLearning.AI Short Courses: pick 6–8 (RAG, evals, agents)
  • Full Stack Open — Parts 6–8 (Redux, GraphQL)
  • System Design Primer GitHub — read first 60%
RAG chatbot over a PDF corpus — FastAPI + LangChain + Pinecone + deployed to HF Spaces
~20h/week · ~80h total
Month 04 · Architecture + Cloud
Scale and Design
  • System Design: ByteByteGo newsletter + 3 mock designs/week
  • DDIA — Chapters 4–9 (distributed systems)
  • Full Stack Open — Parts 9–12 (TypeScript, containers)
  • AWS SAA-C03 prep begins (using 50% discount from CLF pass)
  • Harvard CS50 Cybersecurity (free cert)
Design doc for a URL shortener + a rate-limited REST API with Docker + K8s basic deploy
~18h/week · ~72h total
Month 05 · MLOps + Product
Production AI + Startup Thinking
  • DeepLearning.AI MLOps Specialization — Courses 1–3
  • Y Combinator Startup School (7 weeks, 1–2h/week)
  • Stanford Algorithms Specialization (start with Course 1)
  • Cisco Ethical Hacker (free NetAcad cert)
  • System Design: Complete remaining 40%
AI SaaS product: build, launch on ProductHunt, write post-mortem
~20h/week · ~80h total

Lead and Ship
  • Read The Manager's Path — full book (~10h)

Scholarship & Financial Aid Opportunities

Egypt qualifies for most of these. Apply early — some have limited slots.

Coursera Financial Aid

Available on thousands of courses and professional certs (Google, IBM, DeepLearning.AI, Stanford, etc.). Apply per individual course on the course page — look for "Financial aid available, learn more" below the enroll button. Submit a 150-word application explaining need and goals. Approval in ~15 days. Egypt qualifies. Covers full certificate access.

coursera.org → apply per course page

AWS Educate — Emerging Talent Community (ETC)

Earn points by completing AWS Skill Builder courses. Redeem for free exam vouchers (4,500 pts for Cloud Practitioner, 5,200 pts for Associate). 100% free path to AWS certification with no upfront cost. Available globally including Egypt. Create account at aws.amazon.com/education/awseducate

aws.amazon.com/education/awseducate

Attend a free Microsoft Virtual Training Day event and receive a free voucher for the corresponding exam (AI-900, AZ-900, DP-900). Check scheduled dates at learn.microsoft.com/en-us/training/browse. Available globally. Vouchers typically valid for 6 months.

Foundation Gaps to Fix First

Based on your profile, these are the specific holes that cap your ceiling as an engineer, architect, and technical lead. Fix these before trying to go deeper in specializations.

Gap
CS Theory & Low-Level Programming
Why It Matters
You know frameworks but may not own the mental model underneath. C, memory management, pointer arithmetic — these make you 3x better at debugging, performance, and security. Senior engineers notice this gap immediately.
Fix It With
CS50x (Weeks 1–5 alone justify the whole course) + OSTEP book
Gap
Systematic DSA + Algorithmic Thinking
Why It Matters
Mid-level devs often have fragmented DSA knowledge — they know arrays but freeze on graphs or DP. This directly blocks FAANG-level interviews and contributes to poor solution design under pressure.
Fix It With
NeetCode 150 (free, daily) + Stanford Algorithms Specialization (Coursera aid)
Gap
Distributed Systems & Architecture Thinking
Why It Matters
You build APIs and services but may not have a framework for trade-offs: CAP theorem, eventual consistency, replication lag, message queues vs. sync calls. This is what separates mid-level from senior/staff engineers and architects.
Fix It With
DDIA Chapters 4–9 + System Design Primer GitHub + ByteByteGo newsletter
Gap
Container Orchestration & Production Infrastructure
Why It Matters
You know Docker basics and CI/CD basics, but production infrastructure (K8s, monitoring, observability, IaC) is where most mid-level engineers stall. Cloud-native is the default now — you need to own this layer.
Fix It With
Docker + K8s Practical Guide (Udemy) + Full Stack Open Parts 11–12 + AWS Cloud Practitioner
Gap
ML Theory Under LLM Applications
Why It Matters
